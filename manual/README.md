# シクロクロス用信号機の取扱説明書

## 1. 注意点

### ● コネクタの差し込み方

白い点を合わせて、奥まで差し込んでください。

カップリングナット（抜け止め用ナット）を**締めるときは指先で軽く回すこと**。軽く回らない場合は、正しく勘合していません。いったん抜いてやり直してください。

![青コネクタの差し込み](CX_SIGNAL_02.JPG)

### ● ケーブルを踏まないでください。

### ● 取り外したときはキャップをかぶせてください。

### ● キャップでソケットを保護した状態であれば、水洗いが可能です。

水洗いの前に、ケースのソケットにはキャップが取り付けられているか確認してください。ケーブルのコネクタにはカバー用のソケットを取り付けてください。

### 接続状態

赤のコネクタは赤のソケットに、青のコネクタは青のソケットに差し込んでください。ホイッスル用の透明な箱には青いソケットが4つありますが、差し込む場所はどこでも構いません。

![接続状態](CX_SIGNAL_03.JPG)

## 3. 動作確認

### 赤点灯

スイッチを赤側にして、ACコンセントを差し込むと、次のようになります。

- 橙：2つ点灯（電源が供給されていると点灯）
- 赤：2つ点灯（スイッチが赤側のとき点灯）

![赤点灯](CX_SIGNAL_04.JPG)

### 緑点灯

スイッチを青側にすると、次のようになります。

- 緑（上）：2つ点灯（スイッチが緑側）
- 白（下）：2つ点灯（ホイッスル発音中）

![緑点灯](CX_SIGNAL_05.JPG)

### 緑点灯（制御箱）

スイッチを青側にしてから2秒後は、次のようになります。

- 白（下）：消灯（ホイッスル自動停止）

![緑点灯（制御箱）](CX_SIGNAL_06.JPG)
