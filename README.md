# シクロクロス信号機

製品ドキュメントの入口。このリポは履歴を維持する。リベースしない。

親ディレクトリ `../` は git 管理しない。兄弟ディレクトリがカテゴリごとの独立リポ。

## リポ構成

| リポ | パス | 履歴 |
| --- | --- | --- |
| docs | `.` | 維持する |
| firmware | [`../firmware`](../firmware/) | 維持する |
| hardware | [`../hardware`](../hardware/) | リベースしてよい |
| cad | [`../cad`](../cad/) | リベースしてよい |

手元では次の並びに clone する。

```text
products/cx-signal/
  docs/
  firmware/
  hardware/
  cad/
```
